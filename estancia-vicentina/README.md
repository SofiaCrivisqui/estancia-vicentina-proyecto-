# Estancia Vicentina

**Abrí LEEME.html** para instrucciones completas y EDITOR.html para editar textos y contacto.

Stack: HTML + CSS + JavaScript sin frameworks ni instalación.

Abrí index.html con doble clic o con Live Server. Descomprimí el ZIP completo antes de abrirlo.

La entrega incluye Home, Loteo y Contacto responsive, recursos locales, editor de configuración, validación frontend y eventos para GTM / Meta Ads / Google Ads. El plano es provisorio.

Pendientes para producción: plano final, enlaces sociales, dominio, endpoints de formulario/newsletter y configuración de etiquetas/conversiones en las cuentas. Ver docs/INTEGRACION.md. No hay backend PHP/SMTP incluido.
